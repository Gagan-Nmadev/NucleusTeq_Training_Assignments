# Data Processor Task

A Python training assignment demonstrating core Python concepts
through a Member Data Management System.

## Features

- Store member data using Lists and Dictionaries
- Validate member data
- Clean input strings
- Validate email and phone numbers using Regular Expressions
- Use Object-Oriented Programming
- Handle errors using Custom Exceptions
- Use Lambda functions and filter()
- Package the project as a Python Wheel

## Python Concepts Used

- Lists
- Dictionaries
- Functions
- Modules
- OOP
- Exception Handling
- Custom Exceptions
- Lambda Functions
- filter()
- Regular Expressions
- String Slicing
- Python Packaging
